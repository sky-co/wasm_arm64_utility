WebAssembly / AArch64 Toolbox

Wasm inspection (including uploaded WAST memory layout), AArch64 assembly/disassembly, and 32-bit number conversion.

1. wast2json

Paths are relative to the project root. Supports .wast / .wat / .wasm files and HTTP(S) URLs.

Local conversion creates or overwrites the matching JSON and numbered Wasm files next to the source. Remote files are saved in the service's temporary directory.

Ready to convert.

2. wasm-objdump

Output from wasm-objdump -d -x will appear here.

3. AArch64 Disassembler

Enter 8 hexadecimal digits, optionally prefixed with 0x and suffixed with U. Automatically converts to little-endian bytes.

Ready to disassemble.

4. AArch64 Assembler

Uses llvm-mc to display little-endian bytes and the 32-bit instruction word with a U suffix.

Ready to assemble.

5. AArch64 Binary to Hex

Enter 0 or 1 per box, from bit 31 to bit 0, then click translate. Four bits = one hex digit.

Fill all 32 bits and click translate.

6. 32-bit Base Converter

Unsigned: 0-4294967295. Edit any field, then click Convert. The last edited field is the source.

32 bits; binary grouped by four. No server required.

7. WAST Memory Layout Explorer

Like wasmcodeexplorer: upload a WAST containing module definitions, then inspect linear memory initialization and data segment placement.

Upload a file, then inspect memory layout.

No memory visualization yet.
